# ADR-0004: 문서 파일의 정본 포맷으로 JSON 채택

- 상태: 채택
- 날짜: 2026-11-16

## 배경

`.quire` 파일 안에 문서 내용을 담을 정본 포맷으로 JSON, HTML, Markdown을 검토했다.
기준은 Quire 문서 모델(01)을 손실 없이 저장하고 다시 열 수 있는가이다.

## 비교

| 기준 | JSON | HTML | Markdown |
|---|---|---|---|
| 쪽 설정, 구역, 머리말·꼬리말 | 그대로 표현 | 자체 속성 방언 필요 | 불가 |
| 블록 경계를 넘어 겹치는 주석 (L7) | 오프셋 범위로 표현 | 트리라서 요소 분할 또는 표식 필요 | 불가 |
| 문단 분할·병합 변경 추적 (L6) | 주석으로 표현 | `<ins>`/`<del>`로 문단 표식 삭제 표현 불가 | 불가 |
| 병합 셀, 글상자, 어울림 이미지 | 가능 | 일부, 방언 필요 | 불가 |
| 스키마 검증, 마이그레이션 | JSON Schema로 명확 | 관대한 파서가 조용히 보정 | 방언 다수 |
| 파싱 결정성 | 높음 | 공백·엔티티·태그 보정 개입 | 렌더러마다 다름 |
| 보안 | 데이터일 뿐 | 열 때마다 정제 필요 | 내장 HTML 정제 필요 |
| 사람이 읽기, 바로 보기 | 불편 | 브라우저로 바로 열림 | 가장 쉬움 |

## 결정

- `.quire`의 정본은 **JSON (`document.json`)** 이다.
- HTML, Markdown은 교환 포맷(가져오기·내보내기)으로 지원한다.
- 읽기 불편함은 `.quire` 안의 선택적 `preview/index.html`과 Markdown 내보내기로 보완한다.

## 결과

- HTML을 정본으로 쓰면 L6, L7을 표현하기 위해 결국 비표준 방언이 되므로 HTML의 장점(바로 열림)도 반감된다.
- Word(DOCX)·한글(HWPX)도 같은 이유로 정본은 구조화 포맷(XML)이고 보기용 포맷은 따로 둔다.
