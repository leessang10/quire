# 04. 렌더링과 접근성

- 상태: 설계 (1–6단계에서 구현함. 구현하며 바뀐 점과 결과는 09–16의 결과 절에 있다)
- 해결 대상: L5 (렌더링 측), 그리고 캔버스 채택으로 잃는 기능의 복구

## 1. 요구사항

- R1. 화면에 보이는 쪽만 그린다. 문서 크기와 무관하게 프레임 비용이 일정하다.
- R2. 고해상도(devicePixelRatio) 화면에서 선명하고, 줌 25%~400%를 지원한다.
- R3. 캐럿, 선택, 원격 커서, 주석 하이라이트는 본문을 다시 그리지 않고 갱신한다.
- R4. 스크린리더(NVDA, JAWS, VoiceOver, TalkBack)로 문서를 읽고 편집할 수 있다.
- R5. 찾기, 맞춤법 검사, 복사·붙여넣기, 브라우저 번역 등 `contenteditable`이 공짜로 주던 기능을 대체한다.

## 2. 렌더러 구조

```
스크롤 컨테이너 (DOM, 전체 문서 높이)
└─ 보이는 쪽마다 1개의 쪽 요소
   ├─ <canvas> 본문 레이어     : 텍스트, 표 선, 이미지 (쪽 내용 바뀔 때만 다시 그림)
   ├─ <canvas> 오버레이 레이어  : 선택, 주석 하이라이트, 원격 선택
   └─ DOM 캐럿 / 원격 커서 이름표 (깜박임 애니메이션을 CSS로)
```

- 쪽 단위 캔버스를 쓰면 스크롤 시 화면 밖 쪽의 캔버스를 재사용(풀링)하고, 쪽 내용이 그대로면 다시 그리지 않는다.
- 쪽 하나가 매우 크거나 줌이 높으면 쪽 캔버스를 타일로 나눈다.
- 글리프 그리기: 1차는 Canvas 2D `fillText`(글꼴은 FontFace로 등록한 같은 파일). 레이아웃 엔진이 계산한 글리프 위치에 런 단위로 그린다. 셰이핑 결과와 브라우저 렌더링의 글리프 차이가 문제가 되면 2차로 글리프 경로(path) 캐시 렌더링을 도입한다 (ADR-0002 참고).
- 이미지: 디코드된 `ImageBitmap` 캐시, 줌 수준별 축소본.

## 3. 접근성 미러

캔버스는 스크린리더에게 보이지 않으므로, **레이아웃 트리에서 만든 의미 있는 DOM**을 따로 유지한다.

- 미러는 화면 밖에 두되 `display:none`이 아닌 방식으로 숨긴다 (스크린리더가 읽을 수 있게).
- 구조: 쪽 → 제목(h1~h6) / 문단(p) / 목록(ul, ol, li) / 표(table) / 그림(img + alt) 의 실제 HTML 시맨틱.
- **범위**: 문서 전체가 아니라 캐럿 주변과 화면에 보이는 영역 ± 여유분만 유지한다 (L5). 스크린리더의 "다음 제목으로 이동" 같은 탐색은 문서 개요(제목 목록)를 별도로 전체 유지해 지원한다.
- 캐럿·선택을 미러의 DOM Selection과 동기화해 스크린리더가 현재 위치를 읽게 한다.
- 편집 결과 안내는 `aria-live` 영역으로 알린다 (예: "굵게 켜짐", "표 2행 3열").
- 경로 A/B 입력 요소(03)와 미러의 포커스 관계를 정의한다: 포커스는 입력 요소, 읽기 대상은 미러 (`aria-activedescendant` 또는 동등 기법). 스크린리더별 실제 동작은 0단계에서 검증한다.

## 4. 찾기

- 브라우저 Ctrl+F는 캔버스 텍스트를 찾지 못한다 → 단축키를 가로채 자체 찾기 막대를 연다.
- 문서 모델 텍스트에서 검색하고, 결과는 비영속 주석(`persistent: false`)으로 하이라이트한다. 대형 문서는 Worker에서 검색한다.

## 5. 맞춤법 검사

- 브라우저 내장 맞춤법을 쓸 수 없다. 선택지:
  1. 외부 맞춤법 API (한국어는 별도 서비스 필요)
  2. 클라이언트 사전 (Hunspell WASM 등, 한국어 품질 확인 필요)
- 결과는 비영속 주석으로 표시. 문단이 바뀌면 해당 문단만 다시 검사한다.

## 6. 클립보드

- 복사: 선택 → (1) `QuireDoc` JSON 조각(같은 앱 간 손실 없는 붙여넣기), (2) HTML, (3) 평문 세 가지를 동시에 기록한다.
- 붙여넣기 우선순위: `QuireDoc` > HTML(Word, 한글, Google Docs, 웹 정제기) > 평문.
- HTML 정제는 스키마 정규화(01 §6)로 끝나야 하며, 스크립트·이벤트 속성·외부 리소스는 제거한다 (XSS).
- 이미지 붙여넣기: 파일 업로드 경로로 넘긴다.

## 7. 기타 브라우저 기능

| 기능 | 대응 |
|---|---|
| 브라우저 번역 | 미러 DOM이 번역 대상이 될 수 있으나 편집 내용에 반영되지 않음. 지원하지 않음을 명시하고, 자체 번역 기능(AI 플러그인)으로 대체 |
| 인쇄 | 레이아웃 트리 → PDF 내보내기 경로 사용 (브라우저 인쇄는 쪽마다 캔버스를 인쇄 전용 고해상도로 다시 그림) |
| 텍스트 선택 후 사전·검색 (macOS 등) | 미러 DOM 선택 동기화로 일부 지원 여부 검증 |
